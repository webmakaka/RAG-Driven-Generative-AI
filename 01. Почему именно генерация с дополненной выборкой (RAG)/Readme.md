# 01. Почему именно генерация с дополненной выборкой (RAG)

Механизм RAG для генеративного ИИ опирается на два основных компонента: ретривер и генератор.

Ретривер обрабатывает данные и определяет наиболее подходящий метод поиска, например выборку размеченных документов на основе ключевых слов. Полученный результат дополняет пользовательский ввод и передается в генератор - LLM, который обрабатывает дополненный запрос, выдавая итоговый ответ.

Мы разобрали три основные конфигурации RAG: простую, анализирующую датасеты на основе ключевых слов и прочих методов начального уровня, продвинутую, которая вносит эмбеддинги и индексы, повышая эффективность поиска, и модульную, совмещающую простые и продвинутые техники, а также другие методы машинного обучения.
