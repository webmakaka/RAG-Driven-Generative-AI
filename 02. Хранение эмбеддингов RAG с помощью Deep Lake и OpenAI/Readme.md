# 02. Хранение эмбеддингов RAG с помощью Deep Lake и OpenAI

При реализации проекта с использованием генеративного ИИ на базе RAG так или иначе в определенный момент возникают сложности, вызванные большими объемами данных. В этом случае мы прибегаем к помощи эмбеддингов, преобразуя громоздкие структурированные или неструктурированные тексты в компактные высокоразмерные векторы, отражающие семантическую суть этих текстов. Такое преобразование позволяет увеличить скорость и эффективность извлечения нужной информации. Тем не менее нам неизбежно придется решать проблемы хранения эмбеддингов, создаваемых в ходе работы с увеличивающимися наборами данных.

Эмбеддинги — это любые данные (текстовые, изображения или аудио), преобразованные в вещественные числа. То есть они подразумевают преобразование документа в вектор. Такие математические представления документов позволяют вычислять расстояние между документами и извлекать из них схожие данные.
